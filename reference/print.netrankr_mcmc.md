# Print netrankr_mcmc object to terminal

Prints the result of an object obtained from
[mcmc_rank_prob](https://schochastics.github.io/netrankr/reference/mcmc_rank_prob.md)
to terminal

## Usage

``` r
# S3 method for class 'netrankr_mcmc'
print(x, ...)
```

## Arguments

- x:

  A netrank object

- ...:

  additional arguments to print
