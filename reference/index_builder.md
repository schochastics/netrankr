# Centrality Index Builder

This shiny gadget can be used to build centrality indices based on
specific indirect relations, transformations and aggregation functions.
use the dropdown menus to select components that make up the index.
Depending on your choices, some options are not available at later
stages. At the end, code is being inserted into the current script to
use the index

## Usage

``` r
index_builder()
```

## Value

code to calculate the specified index.
