# Print netrankr_interval object to terminal

Prints the result of an object obtained from
[rank_intervals](https://schochastics.github.io/netrankr/reference/rank_intervals.md)
to terminal

## Usage

``` r
# S3 method for class 'netrankr_interval'
print(x, ...)
```

## Arguments

- x:

  A netrankr_interval object

- ...:

  additional arguments to print
